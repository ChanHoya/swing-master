# 03. MVP 기능 명세 (Features)

## 기능 그룹

| 그룹 | 코드 | 설명 |
|------|------|------|
| 영상 업로드 | A | 스윙 영상 제출 흐름 |
| 포즈 분석 | B | AI 스윙 지표 추출 |
| 피드백 표시 | C | LLM 생성 교정 리포트 |
| 사용자 히스토리 | D | 분석 기록 저장 & 조회 |

---

## A. 영상 업로드

### A-1. 영상 파일 선택 & 업로드
- **입력**: MP4 / MOV, 최대 100MB, 5~30초
- **출력**: `upload_id` (UUID)
- **검증**: 파일 크기, 형식, 최소 길이 체크
- **UX**: 드래그앤드롭 + 파일 선택 버튼

### A-2. 업로드 진행 표시
- 진행률 프로그레스 바 (0~100%)
- 업로드 완료 → 자동으로 분석 시작

### A-3. 분석 상태 폴링
- `GET /analysis/{upload_id}/status`
- 상태: `queued` → `processing` → `done` / `failed`
- 폴링 간격 2초, 최대 60초 타임아웃

---

## B. 포즈 분석

### B-1. 핵심 프레임 추출
- 스윙 어드레스 / 백스윙 탑 / 임팩트 / 팔로우스루 자동 감지
- MediaPipe BlazePose → 33 keypoints per frame

### B-2. 7가지 스윙 지표 계산

| 지표 ID | 이름 | 설명 | 기준값 |
|---------|------|------|--------|
| `spine_angle` | 척추 각도 | 어드레스 시 척추 기울기 | 30~45° |
| `hip_rotation` | 힙 회전 | 백스윙 → 임팩트 힙 회전량 | ≥ 45° |
| `shoulder_rotation` | 어깨 회전 | 백스윙 어깨 회전량 | ≥ 90° |
| `knee_flex` | 무릎 굴곡 | 어드레스 무릎 각도 | 20~30° |
| `head_movement` | 헤드 무브먼트 | 스윙 중 머리 이동 거리 | ≤ 5cm |
| `weight_transfer` | 체중 이동 | 임팩트 시 왼발 체중 비율 | ≥ 60% |
| `tempo_ratio` | 템포 비율 | 백스윙/다운스윙 시간 비율 | 3:1 |

### B-3. 오버레이 이미지 생성
- keypoint 스켈레톤을 원본 프레임에 오버레이
- 이상 관절은 빨간색으로 하이라이트

---

## C. 피드백 표시

### C-1. 종합 점수
- 7개 지표 가중 평균 → 0~100점 (등급: A/B/C/D)
- 레이더 차트 시각화

### C-2. LLM 교정 피드백
- 상위 3개 개선 포인트에 대한 한국어 피드백 (각 2~3문장)
- 교정 우선순위 자동 정렬 (점수 낮은 순)

### C-3. 맞춤 드릴 추천
- 문제 지표별 드릴 1~2개 제안
- 드릴 이름, 방법 (3~5단계), 반복 횟수 포함

### C-4. 비교 시각화
- 현재 자세 vs. 이상적인 자세 side-by-side 이미지

---

## D. 사용자 히스토리

### D-1. 익명 세션 (로그인 불필요)
- 로컬스토리지에 `upload_id` 배열 저장
- 최근 5회 분석 조회 가능

### D-2. 간이 계정 (MVP 선택 기능)
- 이메일 + 비밀번호 회원가입
- 무제한 분석 기록 저장
- 기간별 점수 트렌드 라인 차트

---

## API 엔드포인트 요약

| Method | Path | 설명 |
|--------|------|------|
| `POST` | `/upload` | 영상 업로드 & 분석 시작 |
| `GET` | `/analysis/{id}/status` | 분석 상태 조회 |
| `GET` | `/analysis/{id}/result` | 분석 결과 조회 |
| `GET` | `/history` | 사용자 분석 이력 |
| `POST` | `/auth/register` | 회원가입 |
| `POST` | `/auth/login` | 로그인 |
