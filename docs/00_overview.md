# 00. 서비스 개요 (Overview)

## 서비스 정의

**Swing Master**는 골프 아마추어 플레이어가 스마트폰으로 촬영한 스윙 영상을 업로드하면, AI가 신체 포즈를 분석하여 **구체적인 교정 피드백과 맞춤형 드릴**을 제공하는 웹 서비스입니다.

### 핵심 가치 제안
- 레슨 비용 없이 **즉각적인 전문가 수준 피드백**
- 영상 한 장으로 **7가지 핵심 스윙 지표** 자동 분석
- AI 생성 **맞춤형 교정 드릴** 제공 (텍스트 + 이미지)

---

## 타겟 사용자

| 세그먼트 | 설명 | 규모 (한국) |
|----------|------|-------------|
| 아마추어 골퍼 | 핸디 15~36, 혼자 연습하는 주말 골퍼 | ~300만 명 |
| 초보 골퍼 | 입문 1년 이내, 스윙 기초 정립 필요 | ~50만 명/년 |

---

## 성공 기준 (MVP 기준)

| 지표 | 목표값 | 측정 방법 |
|------|--------|-----------|
| 분석 성공률 | ≥ 90% | 업로드된 영상 중 포즈 추정 성공 비율 |
| 분석 소요 시간 | ≤ 30초 | 업로드 완료 → 피드백 화면 표시 |
| 사용자 만족도 | ≥ 4.0/5.0 | MVP 테스터 설문 평균 |
| DAU (1주차) | ≥ 50명 | 클로즈드 베타 참여자 |

---

## 범위 외 (Out of Scope — MVP)

- 실시간(라이브) 스윙 분석
- 멀티 플레이어 / 소셜 기능
- 클럽 추천 / 장비 분석
- 모바일 앱 (iOS/Android 네이티브)
